Prime number: 
1, itself

Any number can be represented as product of prime numbers
Prime Factorization = p1^a1 x p2^a2 + ... x pn^an

Number of factors = Combinotrics
(a1+1)x(a2+1)...x(an+1)

Sum of factors:
6 = 2^1 x 3^1
00, 01, 10, 11
1, 3, 2, 6 => + => 12
Geometric Progression for 
n = 1 + n + n^2 + n^3 +...+n^k
n = (n^(k+1) - 1) / (n - 1)
6 -> GP (2) x GP (3)
((2^(1+1) - 1) / 2 - 1) x (3^2 - 1)/(3-1)
3 x 4 = 12

Product of factors:
6
1 3 2 6
or
1 2 | 3 6
1x6 x 2x3
6x6
6^2 => 6^(sum of factors) / 2 => 6^(4/2)

Perfect Numbers:
sum of its proper divisors (except itself) == number itself
6 = 1 + 2 + 3
sum of factors - number == number


Density of primes:
number of primes available < n ~= n/logn

Conjecture: any even number can be sum of 2 primes (verified till 4x10^18)
Twin prime Conjecture: adjacent primes with diff < 2 are infinite
Proved till 10^18 that between n^2 and (n+1)^2 there exists a prime number

// Check Prime
bool isPrime (int n) {
  if(n<2) {
    return false;
  }
  for(int i = 2; i*i<=n; i++) {
    if(n%i == 0) return false;
  }
  return true;
}

// Prime Factorization
vector<int> primeFactorization (int n) {
  vector<int> factors;
  for(int i=2; i*i<=n; i++) {
    while(n%i == 0) {
      factors.push_back(i);
      n/=i;
    }
  }
  if(n>1) {
    factors.push_back(n);
  }
  return factors;
}
