Properties of Euler's Totient:
1. For a prime number p: phi(p) = p-1
2. For a power of a prime p^k: phi(p^k) = p^k - p^(k-1)

GCD{4,6} = 2 -> 2 is multiple of {4,6} -> Non coprime
GCD {3,4} = 1 -> They dont have multiples -> coprime

Between 1 and p^k, multiples of p are p,2p,3p,...p^(k-1).p => Total multiples = p^(k-1)

phi(p^k) = Total numbers - multiples/Non coprime
phi(p^k) = p^k - p^(k-1)

p=3, k=2
p^k = 9

phi(9) = 9 - 3 = 6 (Verified)

3. phi(a*b) = phi(a)*phi(b)
4. Gauss's divisor sum property

d|n means d divides n
phi(d) 
sum of all phi(d) from 1 through n == n
n = 10
10 = {1,2,5,10}
phi(1)+phi(2)+phi(5)+phi(10) = 1+1+4+4 = 10 == n (Verified)


Formula for Euler's totient Function:

Any number can be prime factorized -> n = p1^a1 x p2^a2 x p3^a3...x pk^ak
phi(n) = phi(p1^a1 x p2^a2 x p3^a3...x pk^ak)
phi(n) = phi(p1^a1) x phi(p2^a2) x ... x phi(pk^ak)
phi(n) = (p1^a1 - p1^(a1-1)) x (p2^a2 - p2^(a2-1)) x ... x (pk^ak - pk^(ak-1)) 
phi(n) = p1^a1(1-1/p1) x p2^a2(1-1/p2) x ... x pk^ak(1-1/pk)
phi(n) = n x (1-1/p1) x (1-1/p2) x (1-1/pk)

Cute :)

Precompute Totient values:
multiply with (1-1/p)

```text
vector<int> computeTotient (int n) {
  vector<int> phi(n+1);
  for(int i=0; i<=n; i++) {
    phi[i] = i;
  }

  for(int i=2; i<=n; i++) {
    if(phi[i] == i) {
      phi[i] = i-1;
      for(int j=2*i; j<=n; j += i) {
        phi[j] =  (phi[j]/i)*(i-1); // phi[j]*(1-1/i)
      }
    }
  }
  
  return phi;
}
```
