Applications:
1. If GCD(a,m) = 1, then a^phi(m) = 1 (mod m)
2. If p is prime, phi(p) = p-1, a^(p-1) = 1 (mod p)
3. Modular exponentiation simplification
  
a^n => a^(n mod phi(m)) (mod m)

Compute 7^100 mod 10:

a^n === a^(n (mod phi(m))) (mod m)
gcd(7,10) = 1

a = 7
n = 100
m = 10
GCD(7,10) = 1
phi(m) = phi(10) = 4
7^100 = (7^(100 % 4)) % 10
1%10 = 1
* 1%10 = 1

4. Modular multiplicative inverses
a^(-1) === a^(phi(m)-1) (mod m)

3^-1 => let m = 7
phi(7) = 7-1 = 6
=> 3^(6-1) % 7
  243%7 = 5
