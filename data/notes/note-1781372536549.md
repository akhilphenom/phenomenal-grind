Lower bound:
First element >= that number
Number of elements < that number
LB of 4 in 3 3 5 8 9 is 2

Upper bound:
First element > that number
Number of elements <= that number

UB of 4 in 3 3 5 8 9 is 2
UB of 2 is 0
