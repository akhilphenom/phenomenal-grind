Cycles

DFS Tree:
- As a spanning Tree -> minimal edges to connect graph
- We give it a tag
- Every edge will be categorized in to 2 types -> span edges, back edges
- Span edges: u -> v
- Back edges: Additional edges that usually form a cycle. These are vertical
- There are no cross edges in the graph
- If we are at a node, u-> v, v has u as parent, and some other node is also its neighbor but its also visited and not parent, then that edge is a back edge
- https://www.youtube.com/watch?v=wfNnmv5ohAE&list=PLtfqa971vD5FPhwbTJQW0sCLBeMfdkoPH


- There are no cross-edges
- All back edges are vertical


How to find bridges?
Bridge: They can disconnect the graph into two components
- Span edges are the ones that can be used as bridge. Back edges cant be. Think of it. Back edge is a shortcut (vertical) - shortcut doesnt change actual road
- If a back edge is covering span edge, that span edge can't be used as a bridge. Because we still have a shortcut
- Now how do we find? This helps
- We will calculate number of back edges covering a node
- We will use Prefix Sum

void dfs(int u, int parent) {
  vis[u] = true;

  for(auto v: adj[u]) {
    if(v == parent) {
      continue;
    }
    if(vis[v]) { // found back edge from u to v
      dp[u]++;
      dp[v]--;
    } else {
      dfs(v, u);
      dp[u] += dp[v];
      if(dp[v] == 0) {
        //found bridge
      }
    }
  }
}
