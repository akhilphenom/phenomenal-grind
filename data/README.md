# Phenomenal Grind Data

Workspace data is stored in human-readable files:

- `problems.csv` contains the main problem tracker.
- `adhoc-problems.csv` contains ad hoc practice problems.
- `daily/YYYY-MM-DD.md` contains one journal entry per day.
- `notes/<id>.md` contains one note or folder record per file.
- `preferences.ini` contains application preferences.

The application owns the embedded `phenomenal-grind-data` metadata blocks in Markdown files.
Journal prose, note content, rough notes, and code remain visible in the same files.
